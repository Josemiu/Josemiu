## Featured Projects

### [Hybrid Retrieval Engine (RAG)](https://github.com/Josemiu/hybrid-rag) — Applied AI
Retrieval pipeline combining dense embeddings (FastEmbed), BM25 and hybrid fusion (RRF) on Qdrant, evaluated on 94 real queries (recall@10: 0.83 hybrid vs. 0.79 dense vs. 0.68 BM25). Includes cross-encoder reranking and NLI-based evidence verification, with every improvement validated through bootstrap significance testing. Exposed through a REST API, containerized, and covered by CI/CD with 100% test coverage.
`Python` `FastAPI` `Qdrant` `FastEmbed` `Docker` `GitHub Actions`

### [Agent Orchestration Platform](https://github.com/Josemiu/agent-platform) — Applied AI
Multi-agent system (planning, research, retrieval, analysis, verification) built with LangGraph and FastAPI, with asynchronous execution (Redis + workers) and persistent checkpointing for failure recovery. Includes human-in-the-loop (graph pause and resume) and cross-task semantic memory with Qdrant. Evaluated single-agent vs. multi-agent across 24 real runs: 0% hallucinations in both modes, with multi-agent costing ~5.5x more and taking ~7.2x longer per task.
`Python` `LangGraph` `FastAPI` `Redis` `Qdrant`

### [LPPET](https://github.com/xHianx/LPPET) — Mobile & Backend
Cross-platform mobile app for pet adoption management, connected to a Flask backend with a hybrid architecture (MySQL and MongoDB), asynchronous REST APIs for user management, and real-time push notifications.
`Flutter` `Dart` `Flask` `MySQL` `MongoDB` `Firebase Cloud Messaging`
**Status:** 🚧 In progress
